# QuickView Stealth WebTools

Webtool praktis berbasis web untuk membaca teks dan memunculkan jawaban ringkas secara instan & samar (stealth overlay) di Chrome Android.

## Cara Deploy ke GitHub Pages:
1. Ekstrak file zip ini di komputer/HP Anda.
2. Buat Repository publik baru di GitHub (misal: `quickview-tool`).
3. Upload seluruh file (`index.html`, `style.css`, `app.js`, `README.md`) ke repository tersebut.
4. Masuk ke **Settings** -> **Pages** -> Pada bagian *Build and deployment*, pilih branch `main` / `root`, lalu klik **Save**.
5. Buka link GitHub Pages yang diberikan setelah beberapa saat.

## Cara Pakai di Chrome Android:
1. Buka link webtool Anda di Chrome Android.
2. Masukkan API Key (Gemini API Key) dan simpan.
3. Tambahkan halaman ke **Bookmark** atau jadikan Shortcut ke Home Screen.
4. Saat di halaman web target, aktifkan webtool, tap tombol melayang (`⚡`) untuk membaca teks/soal yang sedang dibuka, dan jawaban akan muncul samar selama 1 detik di bagian atas layar.
